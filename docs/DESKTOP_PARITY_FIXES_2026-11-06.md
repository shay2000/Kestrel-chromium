## Implementation

- Address focus: CEF page activation no longer invokes the content-click callback. That callback clears address editing, so calling it when the native address field makes its page key undid the requested focus. Actual content clicks still clear editing and select the pane. The native editor stays mounted underneath the formatted URL, and the address shortcut focuses/selects it synchronously before another key event can arrive. Repeated focus reuses an already active editor, rather than replacing it with the NSTextField and ending its session. Its collapsed appearance is retained.
- Split page ownership: each persistent CEF browser has one weakly held SwiftUI host. A new host supersedes its predecessor before the old view is dismantled. Outgoing single-page/split hosts cannot hide the new host's window, remove its toolbar accessibility, or reset its overlay state.
- Native creation: reserve each tab before calling CEF, whose synchronous window creation can service AppKit reentrantly. A second host waits for the published browser and retries through the page generation. Revalidate the tab/model and runtime after creation; a tab closed or quit in that interval cannot publish an orphan browser. Native diagnostics record only tab/model/browser/window identity. The desktop suite now requires exactly the expected fixture renderer documents, URLs, ready state and headings over read-only CDP, without driving browser actions through CDP.
- Split keyboard commands: Kestrel intercepts its configured Command-arrow bindings before Chromium's history accelerators. The native route and menu share the same tab/search placement operation, respect shortcut recording, and apply only to a browser document without a sheet.
- Application quit: Command-Q is routed through `NSApp.terminate`, including extension popups, before Chromium's renderer can consume it. CEF's existing cancellation/termination handler remains responsible for closing browsers; modal panels and shortcut capture retain their normal handling.
- SwiftPM discovery: generated app, CEF and dependency trees are excluded from the root source target, with an explicit default localisation. Retained WebKit-only integration tests are guarded from the Chromium target; portable and shared assistant/settings tests remain included.
- Saved Chats: the signed WebKit 1.0.0 release has App Sandbox enabled; the CEF main app's preferences are outside that container. Startup imports the legacy transcript archive only when the new archive key is absent. Any existing value, including an intentionally empty archive, is preserved. The reader accepts only a regular, current-user-owned file, refuses links, caps preferences/archive bytes at 8/4 MiB, validates and re-encodes the transcript schema, and leaves the legacy file untouched. Other settings, opt-ins, browser data and credentials are not migrated. The app retains `UserDefaults.standard`.
- Configured shortcuts and archive acceptance: the runner waits for the previous app to exit and uses per-engine preference writes/readback. Chromium's CI menu fixture now puts all 12 records in the actual legacy container, clears the new archive, and requires startup `migrated=true`, 12 loaded records and the 5/5/2 native submenus. Five regression cases cover schema-only copying, preserving existing/deleted chats, malformed/missing files, size bounds and links.
- Desktop acceptance: accessibility traversal now follows the document, its on-screen CEF page windows and the focused native panel. The old first-window-only traversal missed valid split controls. Input and menu commands target the exact process ID; both comparison apps share a name and bundle ID. Resizing targets the actual main document and verifies its frame, with the wide size bounded to the runner display and the narrow size set to 780×620. A clean CEF profile isolates layout comparison from Dark Reader's injected CSS; the extension-acceptance profile is restored afterwards. The stress workflow retains failed first attempts, exercises keyboard and menu split transitions, and includes normal Chromium tab close/reopen, draft/attachment persistence, Agent-mode toggling and Settings close.
