# Kestrel Chromium 1.0.1 — Native window integration preview

Keeps Kestrel's frame active when you click into a webpage, makes the toolbar respond on the first return click, and moves address entry to the actual native search field. Address submission uses the editor's current text. The page now joins the toolbar without rounding its upper corners separately. Toolbar dragging and window controls operate the whole Kestrel document. The toolbar also follows the HTML canvas colour when the body is transparent, matching the original WebKit presentation. The native Swift interface embeds Chromium through CEF.

Extension installation stays in Kestrel's profile. Auxiliary Chromium install UI is handled whether it uses CEF's default client or inherits an existing app client; eligible initial welcome/options pages open as Kestrel tabs. The native acceptance uses real macOS pointer events for Google Translate and Dark Reader installation, checks for extra Chromium address bars, invokes an extension options page and verifies Dark Reader again after restart. These checks do not establish catalogue-wide extension compatibility or complete `chrome.tabs`/`chrome.windows` API behaviour. Native extension action popups and the Settings import flow still need acceptance.

Also fixes a crash caused by ordinary refused/DNS/network failures: an invalid certificate-error range trapped while classifying the failure. The native test deliberately refuses a connection and verifies recovery to a working page.

Download **Kestrel-Chromium-1.0.1-arm64.dmg** and its `.sha256` sidecar. The app bundle now reports **1.0.1**, distinguishing it from both earlier 1.0.0 previews. Apple silicon only, macOS 14+ deployment target. The app is **ad-hoc signed and not notarised**; macOS may block its first launch. No Intel binary, Developer ID/Gatekeeper acceptance or signed automatic-update appcast is supplied.

The release promotes the exact clean DMG from the successful native Mac run recorded below. Publication verifies the original artifact digest, DMG checksum, mounted app version, arm64 architecture and signature, then downloads the uploaded assets and compares their hashes before publishing. The CI extension fixture is removed before packaging. Chromium's renderer sandbox and required framework/helper layout are retained.

Physical phone/QR passkey registration and sign-in remain unverified. Chromium's real flow reached Bluetooth setup; a separate virtual FIDO2 check passed. Apple's iCloud Passwords extension needs an Apple-accepted signed browser identity, which this Kestrel build does not have. No paid passkey service, credential-store bridge or fabricated entitlement is added.

The original WebKit release and update feed are unchanged. This preview does not merge the Chromium review branch into `main`.
