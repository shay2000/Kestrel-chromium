# Kestrel Chromium 1.0.2 — Extensions inside Kestrel

Adds installed extension actions to Kestrel's macOS Extensions menu, pinned shortcuts in the browser toolbar, and optional shortcuts beside Chats in the sidebar. Use Settings → Extensions to choose their placement and individual sidebar shortcuts. Chromium's native pin and site-access controls remain available through the puzzle button.

The buttons activate genuine Chromium extension controllers in the selected Kestrel page. Popups stay attached to Kestrel, and eligible initial setup/options pages open as Kestrel tabs. The update fixes missing native toolbar attachment on new tabs and clean restarts, a toolbar-view ownership error during layout/shutdown, and browser pages covering Settings. No standalone Chromium browser is launched.

Native acceptance used the real Google Translate extension, physical macOS pointer input, its native action and actual active-tab API, sidebar/menu actions, its options document, both visible placement toggle states, a clean restart without forced renderer accessibility, and quitting with the genuine popup open. The existing Store installation/restart, native focus/crash and WebKit comparison checks also passed. Compatibility remains bounded to tested extensions and API paths. Packaged shortcut icons do not mirror dynamic badges or artwork; complete tabs/windows API virtualisation is not supplied.

Download **Kestrel-Chromium-1.0.2-arm64.dmg** and its `.sha256` sidecar. Apple silicon, macOS 14+ deployment target. Ad-hoc signed and not notarised. Chromium's renderer sandbox and framework/helper packaging are retained. This release promotes the exact tested DMG without rebuilding; publication verifies the original artifact digest, mounted app version/signature/architecture and uploaded asset hashes.

Phone/QR passkey sign-in remains unverified: the hosted Mac's virtual Bluetooth controller could not power on and no FIDO QR appeared. Apple's iCloud Passwords helper requires an accepted signed browser identity; Kestrel is absent from Apple's current list. No paid passkey service, credential-store bridge or browser-identity spoofing is added.
