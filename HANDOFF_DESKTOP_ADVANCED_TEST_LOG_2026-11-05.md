## Findings

Chromium’s “No saved chats” menu is a reproducible product-level difference: the correct defaults domain retained 12 records, while the menu still claimed it was empty. Chromium’s `Command+Left` binding also appears to navigate back instead of creating split view; the next run will invoke the native Tabs menu after recording the shortcut result. The original Chromium focus timeout was a harness false negative because the screenshot showed the field and suggestion list open. The first WebKit Cmd-W attempt left no accessible app window and remains unverified. The third run also revealed that archived WebKit v1.0.0 has an older “Browse” composer label. The next run will build the current-source WebKit app from the same commit before comparing Assistant controls.

No product fixes are included. A passing harness step will not be treated as proof for flows it does not exercise, including real provider-backed Agent actions, profile filling, page-image delivery, Codex helper sign-in, or physical phone passkey ceremonies.
